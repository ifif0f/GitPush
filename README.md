# GitPush
Этот репозиторий содержит код для проекта на хакатон от команды GitPush, который позволяет превратить большие экраны в ЖК в полезный инструмент: отображение
новостей, количество свободных парковочных мест, количество общедоступных и невыкупленных кладовых, правила ЖК, гарафик вывоза мусора, контакты аварийной службы.

## Установка и запуск
1) Клонируйте репозиторий:
   ```
   git clone -b webApp https://github.com/ifif0f/GitPush.git
   ```
2) Запустите проект `WebGitPush.slnx`
3) Нажмите на зеленую кнопку (стрелочку) запуска (или клавишу F5)

## Данные
Данные, связанные с новостями, парковкой и кладовыми взяты в API Ujin
```
https://hck-api.unicorn.icu/v1/complex/list/?token=ust-...
```
Данные, связанные с правилами ЖК, гарафиком вывоза мусора и контактами аварийной служб хранятся локально в самой программе.
